# Security policy

SRay is pre-release and currently publishes specification and project infrastructure. There is no supported production release yet.

## Report privately

Use [GitHub private vulnerability reporting](https://github.com/azizbek-asadovnzzemu/SRay/security/advisories/new). Include affected revision, reproduction steps using synthetic data, impact and suggested remediation. Never include credentials or real conversation recordings.

If private reporting is unavailable, open an issue containing only a request for a private security contact; do not disclose the vulnerability publicly. Acknowledgement and resolution times are not guaranteed during the project's initial stage. The maintainer coordinates investigation, a fix and disclosure with the reporter.

## Security expectations

No raw audio upload for captions; no transcript logging or automatic conversation persistence; explicit enable/pause boundaries for remote translation; bounded network/pose resources; preserved dependency provenance. Release claims require tests and physical-device validation.
